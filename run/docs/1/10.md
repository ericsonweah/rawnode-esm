**Change:**

```js
const num = (v, d = 0) => Number.isFinite(Number(v)) ? Number(v) : d;
const fix = (v, digits = 1, d = 0) =>
  Number.isFinite(Number(v)) ? Number(Number(v).toFixed(digits)) : d;

const workersInfo = Array.from(workerStats.values())
  .map((s = {}) => {
    const last = Number.isFinite(s.lastProgress) ? s.lastProgress : 0;
    const ageSec = (performance.now() - last) / 1000;
    const age = fix(ageSec, 1, 0).toFixed(1);
    const alive = ageSec < 2 ? GREEN : DIM;
    const bsz  = String(num(s.batchSize, 0)).padEnd(3);
    const ams  = String(fix(s.avgMsPerBatch, 1, 0)).padStart(4);
    const tps  = String(fix(s.throughput, 0, 0)).padStart(4);
    const qrem = String(num(s.queueRemaining, 0)).padStart(4);
    return (
      `${alive}W${s.workerId ?? 0}${RESET} ` +
      `${DIM}b=${RESET}${bsz} ` +
      `${DIM}avg=${RESET}${ams}ms ` +
      `${DIM}⚡${RESET}${tps}f/s ` +
      `${DIM}q=${RESET}${qrem}`
    );
  })
  .join("   ");
```

This removes all direct `.toString()`/`.toFixed()` calls on possibly‑undefined values.

### 2) **worker.mjs** — stable progress payload (already implemented here)

Your current worker posts progress with `batchSize` and `avgMsPerBatch` so the UI can render safely; keep this block as the canonical shape. **If your local worker lacks these fields, adopt the snippet below.**

```js
parentPort?.postMessage({
  type: "progress",
```

### 5) **.github/workflows/trend-book.yml** — GitHub Actions workflow

Create **`.github/workflows/trend-book.yml`**:

```yaml
name: rawnode-esm-trend-book

on:
  push:
    branches: [ main, master ]
  workflow_dispatch:

jobs:
  convert-and-trend:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '22' # Node 20+ is fine; match your local (22.17.0)

      - name: Make output directories
        run: |
          mkdir -p out/reports
          mkdir -p out/artifacts

      # Run your converter; write a date-stamped JSON report (schemaVersion: 1 is now embedded)
      - name: Run conversion (quiet + JSON report)
        run: |
          node run.mjs --target ./src --quiet --json-report --report ./out/reports/report-%DATE%.json

      # Build the weekly trend book (and optional CSV). The script is zero-dep and guarded.
      - name: Build trend book
        run: |
          node tools/trend-book.mjs --dir ./out/reports --recursive --pretty --csv ./out/artifacts/trend-book.csv
          node tools/trend-book.mjs --dir ./out/reports --recursive --pretty --bucket month --out ./out/artifacts/trend-book-month.json

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: rawnode-esm-trends
          path: |
            out/reports/*.json
            out/artifacts/**
          if-no-files-found: warn
```

* Uses only **core Node** + official GitHub Actions.
* Produces weekly JSON + monthly JSON (+ CSV) trend artifacts built from **guarded** reports.
